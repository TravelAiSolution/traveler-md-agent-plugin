# Interview map

Use this map to decide where a confirmed answer belongs. It is not a questionnaire, and it is not a list of things to ask about.

| Section                  | Holds                                                                    |
| ------------------------ | ------------------------------------------------------------------------ |
| `summary`                | Concise overview drawn from the known destination, dates, group, purpose |
| `destinations`           | Confirmed destinations, and options still under consideration            |
| `dates`                  | Exact dates, or the shape of the flexibility                             |
| `travelers`              | Who is going, and group facts specific to this trip                      |
| `purpose`                | Why this trip is happening                                               |
| `budget`                 | Trip-specific budget and the tradeoffs the traveler will accept          |
| `accommodation`          | Where and how to stay on this trip                                       |
| `transportation`         | Local transport, rental car, transfers, walkability                      |
| `flights`                | Origin, cabin, routing and timing tradeoffs. Never a record locator      |
| `activities`             | Experiences wanted, and experiences to avoid                             |
| `restaurants_food`       | Restaurants, cuisines, markets, dining plans                             |
| `itinerary`              | Day by day, or the rough shape of the trip                               |
| `confirmed_bookings`     | Public booking summary only                                              |
| `deadlines`              | Time-sensitive booking, cancellation, visa or payment dates              |
| `documents`              | Private confirmations, and entry/visa and ticket detail                  |
| `during_trip_notes`      | Notes taken while travelling                                             |
| `post_trip_learnings`    | What the traveler concluded afterwards                                   |
| `additional_information` | Only when no more specific section fits                                  |

Sentence caps differ by section. They are in the trip-sections reference linked from this skill's SKILL.md, and the short ones matter here: an interview that keeps appending to `summary` or `purpose` will hit a cap long before it hits one on `itinerary`.

Question selection rules:

- Ask one question at a time by default.
- Start from the highest-value missing or unresolved fact for this specific trip.
- Prefer a short selectable choice when the answer space is naturally bounded.
- Offer "Other" or "It depends" when either is a realistic answer.
- Do not ask for a private identifier unless the user's stated goal needs it.
