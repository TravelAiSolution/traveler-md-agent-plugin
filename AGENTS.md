## Repo guidance lives in CLAUDE.md

`CLAUDE.md` is the canonical agent guide for this repo: what the package is, where every factual
claim in the skill comes from, the Definition of Done and the CI gates. Read it first, before
changing anything under `skills/`. Do not duplicate repo conventions here; add them to `CLAUDE.md` so
the two files cannot drift.

`README.md` is the human-facing overview: what the package contains, how to install it, how to
validate it, and how to keep the skill in sync with the MCP server.
